🟡 Level 5: IP 路由選擇與 OSPF (CCNA)

理解 Layer 3 跨網段路由、子網遮罩與最短路徑計算

💡 承前啟後：為什麼需要 Router？

Level 4 中 VLAN 阻斷了跨部門廣播。當不同網段（IP）要互相傳遞資料時，必須靠 Layer 3 路由器（Router）進行「跨網段導航」，並由 OSPF 動態計算出最佳路徑。

📖 資深工程師講堂：Level 5 核心 IP 路由觀念

1. 前情提要：VLAN 隔離後，如何跨部門通訊？

Level 4 用 VLAN 隔離了廣播。但 Sales 部門（`192.168.1.0/24`）如果要向 Data Center（`10.0.0.0/8`）發送請求，Switch（L2）無能為力。這時必須靠 **Router（L3 路由器）** 檢查目的地 IP，決定下一步該往哪裡轉發。

2. 子網切分 (Subnetting) 與預設閘道 (Default Gateway)

• Default Gateway： 電腦發送封包時，若發現目標 IP 不在同一個子網內，就會自動把封包交給網段出口（閘道路由器）。
• Subnetting (/24, /26)： 精準切割 IP 範圍，避免地址浪費。路由器根據「最長匹配原則 (Longest Prefix Match)」選擇最佳路由目標。

3. 動態路由協定：OSPF 最短路徑優先

大型企業有幾十台 Router，手動設定靜態路由太慢且無法應對斷線。OSPF (Open Shortest Path First) 使用 Dijkstra 演算法計算頻寬代價（Cost），當主路徑（Router B）斷線時，OSPF 能在秒級內**自動切換至備用路徑（Router C）**！
