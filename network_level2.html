理解 Transmission Control Protocol 與防火牆過濾

💡 什麼是 TCP？為什麼要三次握手？

TCP 命名： Transmission Control Protocol（傳輸控制協議），確保資料「不遺失、依序到達」。

三次握手目的： 確認雙方的發送與接收能力正常（1.SYN → 2.SYN-ACK → 3.ACK）。

TCP 連線狀態： CLOSED (未建立)

點擊按鈕啟動握手。

📦 用「寄快遞」輕鬆理解 OSI 與 TCP/IP 模型

為什麼需要模型？ 因為網絡傳輸非常複雜。把網路比作寄一份國際快遞：
• OSI (7層) 是理論上的完全分工手冊。
• TCP/IP (4層) 是現實世界簡化後的實用快遞流程。

OSI 7層 (理論版) 📦 寄快遞生活比喻 TCP/IP 4層 (實用版) 實際網路運作元件
7. Application (應用層) 寫信內容（要寄什麼文字/圖片） 1. Application (應用層) HTTP, LINE, Chrome 瀏覽器
6. Presentation (表示層) 翻譯語言、加密內容 SSL/TLS 加密, JPEG, JSON
5. Session (會話層) 通話確認對方有空（保持對話） 連線狀態維持/斷線重連
4. Transport (傳輸層) 選擇快遞公司（要簽收的順豐或平郵） 2. Transport (傳輸層) TCP (保證送達) / UDP (快速發送)
3. Network (網絡層) 填寫城市與地址、規劃公路導航路線 3. Internet (網際網絡層) IP 地址、路由器 (Router)
2. Data Link (數據鏈路層) 門牌號碼（最後一公里精準配送） 4. Network Access (網絡存取層) MAC 地址、交換機 (Switch)
1. Physical (物理層) 實體卡車、飛機、馬路道路 光纖、網線、Wi-Fi 電磁波
