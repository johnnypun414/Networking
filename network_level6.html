💡 傳統網絡痛點與 SDN 革命

當企業有幾百家分店，逐台敲命令（CLI）設定極易出錯。SD-WAN 將「控制面（大腦）」集中於雲端 Controller，透過 Python / API 即可一鍵下發策略給全球所有分店！

📖 資深工程師講堂：Level 6 高階 SD-WAN 與自動化

1. 痛點爆發：傳統 CLI 設定的終極困境

在 Level 5 中，每台 Router 都有自己的大腦。當企業擴張到 500 間分店時，工程師必須 SSH 登入 500 次敲指令。一旦有人打錯字，分店立即斷線，極難維護。

2. SDN / SD-WAN 核心：控制面與數據面分離

• Control Plane（控制面 - 大腦）： 集中於雲端控制器（如 Cisco vManage / vSmart），統一計算路由與安全原則。
• Data Plane（數據面 - 肌肉）： 放在分店的實體路由器（vEdge），只專心進行高速 IPsec 數據轉發。

3. Cisco CCNP 認證考點：Python 與 REST API

現代網絡工程師不再只會敲命令，而是使用 Python + REST API (JSON) 與 Controller 對話。只需在 Controller 變更範本（Template），系統便會自動將加密隧道（Overlay Mesh）推播至全球端點！
